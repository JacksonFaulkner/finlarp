# 1. What happens: a bit is charge on a capacitor

A DRAM bit is a packet of charge on one tiny capacitor. Full charge reads as 1, empty reads as 0. The cell is one transistor and one capacitor, so it is called 1T1C. The picture for this node is the animation above; the parts are below.

# 2. The parts

word line            row select: high turns on every access transistor in its row
access transistor    a switch between the bit line and the storage node
storage capacitor    holds the bit as charge on its plate
bit line             the column wire; precharged to VDD/2 before each read
sense amp            two cross-coupled inverters on a bit line pair; latches to a full rail
precharge            holds the bit line at VDD/2 between accesses

# 3. One read, in order

1. precharge: the bit line sits at VDD/2
2. word line rises: the access transistor switches on
3. charge sharing: charge moves between the cell and the bit line; the bit line moves a small amount, up for a 1, down for a 0
4. sense amp: the latch drives the bit line to a full VDD or full GND
5. restore: the still-connected cell is driven back to its full charge

The read drains the cell, so the restore step is part of every read, not an extra.

# 4. Refresh: rewrite every row before the charge is gone

The cell leaks, so every row is read and rewritten on a timer. In DDR4 the refresh window is 64 ms. The controller issues 8192 refresh commands in each window, and each one refreshes a slice of rows, so every row gets its turn.

# 5. Leakage: why the charge fades

The leakage drains charge out of the storage node through the capacitor dielectric, the storage-node junction and the access transistor while it is off. The loss is slow and differs from cell to cell, so the refresh window has to cover the weakest cells.

# 6. By the numbers

cell                 1 transistor + 1 capacitor (1T1C)
cell area            6F^2 with an open bit line, 8F^2 with a folded bit line
refresh window       tREFW = 64 ms (DDR4, Micron datasheet value)
refresh interval     tREFI = 7800 ns, 8192 REF commands per window
typical array        512 wordlines x 512 bitlines

# 7. Shrinking the cell: less area means less signal

The cell area is set by F, the minimum feature size (see the LITHO node). The swing on the bit line is (Vcell - VDD/2) x Cc / (Cc + Cb). A smaller storage capacitor gives a smaller swing, so the sense amp has less to work with. Designs keep Cc up with a taller capacitor or a better dielectric.

# 8. Who makes it

Commodity DRAM is made by Micron (MU), SK hynix (000660.KS) and Samsung (005930.KS). Market share and the split between commodity and HBM are covered on the market pages, not here.

# 9. Chokepoints and risks

- Retention varies from cell to cell. The refresh window has to cover the weakest cells, which costs refresh time and power.
- Refresh blocks memory access while it runs, so it slows the system.
- Rapid activation of one row can leak charge into its neighbours (RowHammer), a reliability and security risk.
