# 1. What happens: from tested wafer to bonded die

 ┌────────────┐  ┌────────────┐  ┌─────────────┐  ┌───────────────┐  ┌───────┐  ┌──────────────┐
 │ WAFER SORT │─▶│ WAFER MAP  │─▶│ DICE + TAPE │─▶│ PICK          │─▶│ PLACE │─▶│ BOND         │
 │ probe dies │  │ good / bad │  │ saw / laser │  │ needle+collet │  │ align │  │ TCB / hybrid │
 └────────────┘  └────────────┘  └─────────────┘  └───────────────┘  └───────┘  └──────────────┘

  (only dies marked known-good are picked; bad ones stay on the tape and are scrapped)

# 2. Mechanism: lifting one die off the dicing tape

  ┌──────────────────────────────────────────────────────────────────────────────────┐
  │               PICK-UP COLLET, holds die by vacuum                                │
  │                       ┌─────────────┐ ▲ vacuum line                              │
  │                       │   COLLET    │ arm swings die to the bonder               │
  │                       └─────────────┘                                            │
  │                              ▲          die lifted off tape, peeled from edge in │
  │                         ┌─────────┐                                              │
  │     ▓▓ neighbour dies ▓▓│DIE (KGD)│     ▓▓ neighbour dies ▓▓                     │
  │                         └─────────┘                                              │
  │   ──────────────────────────────────────────────────────────────dicing tape────  │
  │                              │                                                   │
  │                         EJECTOR NEEDLE pushes up                                 │
  │   ════════════════════════════ chuck + vacuum ═════════════════════════════════  │
  └──────────────────────────────────────────────────────────────────────────────────┘

  Peel-off matters because dies are thinned: HBM DRAM dies are tens of um thick (textbook); a wrong
  ejector stroke cracks them. Newer flows use a flip step so the bump side ends up facing down.

# 3. Mechanism: three ways to join the die

  (a) Thermocompression bonding (TCB) with non-conductive film, as in HBM stacks today

  ┌─────────────────────────────────────────────────────────────────────────────────┐
  │         ┌───────────────────────────────────────────┐                           │
  │         │▓▓▓▓ BOND HEAD: heated, pressing down ▓▓▓▓▓│ ◀ heat + force            │
  │         └───────────────────────────────────────────┘                           │
  │               ┌───────────────────────────────┐                                 │
  │               │        upper DRAM die         │                                 │
  │               │     o   o   o   o   o   o     │ ◀ microbumps, solder caps       │
  │               ├───────────────────────────────┤                                 │
  │               │      ≈≈≈≈ NCF resin ≈≈≈≈      │ ◀ film melts, flows out         │
  │               ├───────────────────────────────┤                                 │
  │               │        lower DRAM die         │                                 │
  │               │      TSV  ║   ║   ║   ║       │                                 │
  │               └───────────────────────────────┘                                 │
  │   ════════════════════════════ stage, also heated ═════════════════════════════ │
  │                                                                                 │
  └─────────────────────────────────────────────────────────────────────────────────┘

  Solder bumps melt and wet the pads while the film squeezes out of the joint; then it cures. Each die
  is bonded one at a time (a 12-high stack means 12 cycles), so throughput is the whole game.
  (b) MR-MUF (SK hynix): dies tack-bonded with mass reflow, then a molded underfill is injected at once.
  (c) Hybrid bonding: no bumps at all. Copper pads sit flush in oxide and bond directly:

  ┌─────────────────────────────────────────────────────────────────────────────────┐
  │   upper die   │ oxide ▓▓ Cu ▓▓ oxide ▓▓ Cu ▓▓ oxide │                           │
  │   ──────────  ═══════ bonded interface ═══════════                              │
  │   lower die   │ oxide ▓▓ Cu ▓▓ oxide ▓▓ Cu ▓▓ oxide │                           │
  │   step 1      polish oxide flat (CMP), touch, bond at room temp (textbook)      │
  │   step 2      anneal: Cu expands more than oxide, pads meet and fuse (textbook) │
  └─────────────────────────────────────────────────────────────────────────────────┘

# 4. Why only known-good die

  Stack yield is a product. Illustration (arithmetic, not sourced): if each die in a 12-high stack is
  99% good, 0.99^12 = 88.6% of stacks work; at 95% per die it falls to 0.95^12 = 54.0%. One bad die
  also wastes the 11 good ones and the base die. Hence sort first, stack second, then re-test stacks.
