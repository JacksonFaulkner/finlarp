# 1. What happens: build one wiring level (dual damascene), repeated for M5-M9

 ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
 │ DEPOSIT ILD  │  │ PATTERN+ETCH │  │ BARRIER+SEED │  │ PLATE Cu     │  │ CMP          │  │ CAP+REPEAT   │
 │ low-k stack  │─▶│ trench + via │─▶│ TaN/Ta, Ru   │─▶│ bottom-up Cu │─▶│ strip excess │─▶│ SiCN/SiN cap │
 │ +etch stop   │  │ hard mask    │  │ PVD,ALD,CVD  │  │ ECD tool     │  │ stop on ILD  │  │ next level   │
 └──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘

  (one pass makes one metal level plus the vias below it; M5-M9 is five such passes, each ~4-6 tool visits)

# 3. RC delay: why wire levels get fatter going up

 ┌────────────────────────────────────────────────────────────────────────────────────────────────────┐
 │   wire delay  ~  R x C  =  (rho L / (W H)) x (k eps0 L H / S)  =  rho k eps0 L^2 / (W S)    (textbook)│
 │   R = rho L / (W H)     C = mostly line-to-line, grows with k and with H / S (S = spacing)         │
 │                                                                                                    │
 │   thin M1-M4           medium M5-M9            thick M10-M14                                       │
 │   ┌─┐┌─┐┌─┐            ┌──┐ ┌──┐ ┌──┐          ┌────┐   ┌────┐                                     │
 │   └─┘└─┘└─┘            │  │ │  │ │  │          │    │   │    │                                     │
 │   cell to cell         └──┘ └──┘ └──┘          └────┘   └────┘                                     │
 │   highest R per um     block to block          power, clock, global                                │
 │   (size effect)        balance R and C         lowest R, relaxed pitch                             │
 └────────────────────────────────────────────────────────────────────────────────────────────────────┘

  (Cu resistivity rises as lines narrow: IBM study, ~2.0 uOhm-cm wide lines vs >3.0 uOhm-cm below ~60 nm
      width [6])

# 6. Electromigration: how a Cu line fails

 ┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
 │    electrons ──▶──▶──▶──▶──▶──▶──▶──▶        (current flows opposite)                                  │
 │    ┌──────────────────────────────────────────────────────────────────────┐                            │
 │    │▒▒ void grows here ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ hillock ▒▒▒▒▒▒│                         │
 │    └──────────────────────────────────────────────────────────────────────┘                            │
 │    atoms drift along the weakest path: the Cu / cap interface (textbook)                               │
 │    MTTF = A * J^-n * exp(Ea / kT)   Black's equation, n often about 2 [9]                              │
 │    Cu Ea about 0.7-1.1 eV vs Al 0.5-0.7 eV [9];  fix: CoWP / Co / Ru caps, Mn or Co liners, Cu reflow [4]│

# 10. Who makes it, structure, risks

  Dep/etch/CMP/plating tools: Applied Materials (AMAT), Lam Research (LRCX), Tokyo Electron (8035.T),
      Ebara (6361.T, textbook)
 Fabs: TSMC (TSM), Intel (INTC), Samsung (005930.KS); design side: ARM, NVDA, AMD design to these rules
 EDA RC extraction: Synopsys StarRC (SNPS), Cadence Quantus (CDNS) [12]
  Risks: Cu resistance wall below ~20 nm pitch (switch to Ru), ULK damage, EM at higher current, China at
      30% of AMAT sales,
 and the move of tight levels to subtractive Ru, which changes who sells the tools (textbook).

(notes)
  M5-M9 are the 'intermediate' levels: wider and taller than M1-M4, routed block to block, patterned with
      DUV or EUV.
  Foundries do not publish per-level pitch or k values for all levels; numbers here are disclosed examples
      only.
