# 1. What happens: from tin droplet to printed pattern

 ┌───────────────┐  ┌─────────────────────┐  ┌───────────────┐  ┌────────────────────┐
 │ TIN DROPLET   │  │ 2 LASER SHOTS       │  │ PLASMA        │  │ COLLECTOR          │
 │ ~25 um molten │─▶│ pre-pulse flattens, │─▶│ emits 13.5 nm │─▶│ focuses to the     │
 │ tin, ~50 kHz  │  │ CO2 main pulse      │  │ light         │  │ intermediate focus │
 └───────────────┘  └─────────────────────┘  └───────────────┘  └────────────────────┘
   (row 1 ends at the intermediate focus; row 2 is inside the scanner, same direction of travel)
 ┌──────────────────┐  ┌──────────────────────┐  ┌────────────────┐
 │ ILLUMINATOR      │  │ RETICLE + MIRRORS    │  │ WAFER          │
 │ shapes the beam  │─▶│ reflective mask,     │─▶│ resist absorbs │
 │ onto the reticle │  │ 6 mirrors, 4x shrink │  │ 92 eV photons  │
 └──────────────────┘  └──────────────────────┘  └────────────────┘

  (all of it in vacuum or low-pressure hydrogen: EUV is absorbed by air and by every lens material)

# 2a. The light source (laser-produced plasma, LPP)

  ┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
  │   DROPLET GENERATOR ──▶  ●  ●  ●  ●   tin droplets, ~25 um, ~70 m/s, ~50 kHz                     │
  │                               │                                                                  │
  │        PRE-PULSE laser ══▶    ▼   droplet swells from ~30 um to >100 um (pancake / mist)         │
  │                            ◌◌◌◌◌                                                                 │
  │        CO2 MAIN PULSE ══▶  ≈≈≈≈≈≈≈   10.6 um, 15-25 ns, ~1e11 W/cm2   ──▶ PLASMA ~100 um         │
  │                            ≈≈≈≈≈≈≈   electron temp 20-50 eV, emits 13.5 nm EUV                   │
  │                                  ╲                                                               │
  │    COLLECTOR: ellipsoidal Mo/Si multilayer mirror, ringed around the plasma, aims light          │
  │    at the INTERMEDIATE FOCUS (IF) ──▶ into the scanner. H2 gas (1-10 Pa) sweeps tin off the mirror │
  │    tin debris still builds up: collector loses 0.1-0.3% per billion pulses, swapped ~yearly      │
  └──────────────────────────────────────────────────────────────────────────────────────────────────┘

  (CO2 laser reflecting off the droplet can damage the laser, so the beam train is isolated; per patents)

# 2b. The scanner: reticle to wafer (all mirrors, no lenses)

  ┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
  │       from IF ──▶ ILLUMINATOR (2+ mirrors: shape, homogenise)                                    │
  │                          │                                                                       │
  │                          ▼ ╲ small angle off the normal                                          │
  │         ┌────────────────────────────┐                                                           │
  │         │ RETICLE (reflective mask)  │  Mo/Si multilayer, Ta-based absorber draws the pattern    │
  │         └────────────────────────────┘  scans one way                                            │
  │                          │ reflected pattern                                                     │
  │                          ▼                                                                       │
  │        PROJECTION OPTICS: 6 mirrors (0.33 NA), 4x reduction, Mo/Si ~67-70% reflective each       │
  │                          │                                                                       │
  │                          ▼                                                                       │
  │         ┌────────────────────────────┐                                                           │
  │         │ WAFER on stage, resist     │  scans opposite way, synchronised to the reticle          │
  │         └────────────────────────────┘                                                           │
  └──────────────────────────────────────────────────────────────────────────────────────────────────┘

  Light budget: each mirror reflects ~0.67-0.70, so ~10 mirrors keep <2%; 100 W in, ~1 W at wafer.
  (0.7^10 = 2.8% and 0.67^10 = 1.8%: computed here, matches the <2% patent figure)

# 3. The physics

  Rayleigh resolution    CD = k1 * lambda / NA          DOF = k2 * lambda / NA^2   (textbook)

  0.33 NA  with k1 = 0.33   CD = 0.33 * 13.5 / 0.33 = 13.5 nm   (ASML quotes 13 nm)
  0.55 NA  with k1 = 0.33   CD = 0.33 * 13.5 / 0.55 =  8.1 nm   (ASML quotes 8 nm)
  depth of focus shrinks by (0.55/0.33)^2 = 2.8x, so the resist must be thin and the wafer very flat.

  Photon energy      E = 1239.8 eV*nm / 13.5 nm = 91.8 eV    vs 6.4 eV for 193 nm ArF (14x higher)
  Photons at 30 mJ/cm2   30e-3 J / (91.8 eV * 1.602e-19 J/eV) = 2.0e15 per cm2 = ~20 per nm2
  Same dose in ArF would be ~14x more photons, so EUV has 14x more shot noise: STOCHASTICS.
  Pellicle (membrane over the reticle to stop dust) must pass EUV: NXE:3400B membrane 85-90% (Wikipedia).
  High-NA: 4x/8x anamorphic mirrors, field 26x16.5 mm instead of 26x33 mm, so a wafer takes 2x the shots.

# 6. Who makes it, risks

  ASML (ASML, ASML.AS)      sole maker of EUV scanners; owns Cymer, the San Diego source maker (textbook)
  Carl Zeiss SMT            makes the mirrors; private (Zeiss Group), no ticker (textbook)
  TRUMPF                    CO2 drive laser; private (textbook)
  Lasertec (6920.T)         actinic EUV mask inspection (textbook)
  Hoya (7741.T)             EUV mask blanks (textbook)
  TEL (8035.T)              tracks that join the scanner, see COAT / DEVELOP
  Customers                 TSMC (TSM), Samsung, SK Hynix, Intel (INTC; first High-NA), Micron (MU)

  Chokepoints: one scanner vendor, one mirror maker, one laser maker; ~200 ton tool.
  Price: ASML is pushing value-based pricing beyond productivity gains, TSMC reportedly objects.
  Risks: tin debris, collector life, stochastic defects, High-NA yield and cost, export controls.
