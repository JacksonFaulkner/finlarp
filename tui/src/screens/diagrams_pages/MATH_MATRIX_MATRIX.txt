# 1. Answer cell (i, j) = row i of A dotted with column j of B

   A = [ 1  2 ]     B = [ 5  6 ]
       [ 3  4 ]         [ 7  8 ]

   C[1][1] = row 1 · col 1 = 1 x 5 + 2 x 7 = 5 + 14 = 19

# 2. Fill in all four cells

   C[1][1] = row 1 · col 1 = 1 x 5 + 2 x 7 = 19
   C[1][2] = row 1 · col 2 = 1 x 6 + 2 x 8 = 22
   C[2][1] = row 2 · col 1 = 3 x 5 + 4 x 7 = 43
   C[2][2] = row 2 · col 2 = 3 x 6 + 4 x 8 = 50

   C = [ 19  22 ]
       [ 43  50 ]

# 3. Cost: one dot product per cell

   (m x n)(n x p) takes m x n x p multiplications. Here 2 x 2 x 2 = 8: four cells,
   two multiplies each.

# 4. Why GPUs care

  Large models are mostly huge matrix products. One (4096 x 4096) times (4096 x 4096)
  takes about 69 billion multiply-adds. GPUs run thousands of dot products in parallel, and
  tensor cores do small matrix tiles in a single instruction.
