An open-weight model is a trained model whose parameters are published so others can download, run, and fine-tune it. Licenses differ, and many open-weight releases restrict commercial use or withhold training data and code, so calling them open source is often inaccurate. Releases let companies run inference on their own GPUs rather than paying an API vendor per token. Strong open-weight releases tend to push down per-token prices for hosted models.
