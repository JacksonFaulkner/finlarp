The ACTIVATE command tells a DRAM bank to open one row, copying its cells onto the sense amplifiers so the row buffer holds the data. Reads and writes can only use columns of an open row, so ACTIVATE is a required step before most accesses. Its timing sets the gap before data can move, which affects effective memory bandwidth for AI workloads. Related: Micron (MU), SK hynix (000660.KS), Rambus (RMBS).
