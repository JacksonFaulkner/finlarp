A GPU cluster is many GPU servers connected by a high-speed network so they can train or serve one model together. Large training clusters link tens to hundreds of thousands of GPUs using NVLink inside racks and InfiniBand or Ethernet between them. Cluster size is limited by power, networking and failure rates, so builders talk in both GPU counts and megawatts. Related: Nvidia (NVDA), Arista (ANET), Broadcom (AVGO), CoreWeave (CRWV), Meta (META).
