A vector database stores embeddings, which are lists of numbers that represent the meaning of text, images, or other data, and returns the stored items closest to a query. It uses approximate nearest-neighbor indexes such as HNSW to answer quickly across millions of vectors. Most RAG and semantic search systems depend on one, either as a standalone product or as a feature of a general database. Many existing database vendors now add vector search, so it is often a feature rather than a separate purchase. Related: MongoDB (MDB), Elastic (ESTC), Snowflake (SNOW), Oracle (ORCL).
