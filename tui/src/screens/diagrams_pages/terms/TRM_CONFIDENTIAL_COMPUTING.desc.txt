Confidential computing keeps data encrypted in memory while it is being processed, so the host operating system, hypervisor and cloud operator cannot read it. It is built on CPU features such as Intel TDX and AMD SEV-SNP, plus confidential GPU modes on newer accelerators. For AI infrastructure it lets a cloud run proprietary model weights and customer prompts on shared hardware without exposing them to the provider. Related: Intel (INTC), AMD (AMD), NVIDIA (NVDA), Microsoft (MSFT).
