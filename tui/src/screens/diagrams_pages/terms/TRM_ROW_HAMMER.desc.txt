Row hammer is a DRAM failure mode in which repeatedly opening and closing one row disturbs the charge in nearby rows and can flip bits there. It is a reliability and security concern because a process can corrupt data it should not reach. Vendors mitigate it with in-DRAM logic such as target row refresh, which adds refresh traffic and so costs bandwidth. Related: Micron (MU), SK hynix (000660.KS), Rambus (RMBS).
