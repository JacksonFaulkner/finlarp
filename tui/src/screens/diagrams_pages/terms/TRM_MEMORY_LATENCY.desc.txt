Memory latency is the delay from a CPU or GPU issuing a read to the data arriving back. It is set by DRAM array timing, the memory controller queue, and the trip over the bus or link. Bandwidth and latency differ: a system can move a lot of data per second and still stall on every miss. Expansion memory such as CXL trades extra latency for more capacity.
