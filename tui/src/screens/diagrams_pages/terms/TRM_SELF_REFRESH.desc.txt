Self-refresh is a DRAM low-power state in which the chip refreshes its own rows on an internal timer, and the memory controller stops sending commands. The data stays valid while the interface is quiet, so a device can sleep without losing contents. For AI infrastructure it matters mainly for power management of idle memory and for system suspend, not for active training. Related: Micron (MU), SK hynix (000660.KS), Rambus (RMBS).
