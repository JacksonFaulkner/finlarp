RDMA (remote direct memory access) lets one server's NIC read or write another server's memory directly, without involving either CPU or the operating system. That cuts latency and CPU load, and with GPUDirect it moves data straight between GPU memories across the network. InfiniBand has RDMA built in; RoCE (RDMA over Converged Ethernet) brings it to Ethernet, which is how most Ethernet AI clusters run. Related: Nvidia (NVDA), Broadcom (AVGO), Arista (ANET), AMD (AMD).
