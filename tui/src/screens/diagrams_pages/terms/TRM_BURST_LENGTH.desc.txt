Burst length is the number of data transfers a DRAM device delivers for one read or write command. DDR4 uses a burst of 8, and DDR5 uses 16 on each 32-bit subchannel, so either one fills a 64-byte cache line. Longer bursts raise bandwidth efficiency for streaming work such as model weights, while short accesses suit random reads. The value is set by the memory standard and controller, not by the buyer.
