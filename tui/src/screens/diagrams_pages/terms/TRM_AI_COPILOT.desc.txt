An AI copilot is an assistant built into an existing application that drafts, suggests, or summarizes work while the user keeps control of the final action. It typically reads the context of the open document, record, or codebase and asks the user to accept changes. Vendors usually sell it as a per-seat add-on or as part of a higher-priced tier. Each request carries inference cost, so the economics depend on adoption and on how the vendor routes requests between models.
