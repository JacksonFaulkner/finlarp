The Model Context Protocol, or MCP, is an open standard, first published by Anthropic in late 2024, that lets an AI application connect to external tools and data through a common interface. An MCP server exposes tools, resources, and prompt templates that a compatible host can discover and call. Because a server is written once, it can work across many hosts instead of needing a custom integration for each. The protocol does not decide what a model may do, so the host's approval flow still matters for security. Related: Salesforce (CRM), Atlassian (TEAM), Datadog (DDOG), Palantir (PLTR).
