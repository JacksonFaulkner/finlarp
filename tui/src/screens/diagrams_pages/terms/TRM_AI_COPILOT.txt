# 2. Why AI cares

An AI copilot is an assistant embedded in an existing product, such as a code editor, office suite, or CRM, that drafts output and waits for the user to accept it. Vendors usually charge per seat or bundle it into a higher tier, so revenue depends on how many users adopt it. Each request carries inference cost, so margins depend on model routing and usage caps.
