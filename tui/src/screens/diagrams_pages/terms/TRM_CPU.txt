# 2. Why AI cares

Accelerators need a host to load data and run the control code. Agent and inference workloads also lean on CPUs for tool calls and data prep.

# 3. Business angle

Share shifts between Intel, AMD and Arm-based chips move server CPU revenue and Arm royalties.
