# 1. Multiply every slot by the same number

   3 x [ 1 ]  =  [ 3 ]
       [ 2 ]     [ 6 ]

   slot 1: 3 x 1 = 3
   slot 2: 3 x 2 = 6

# 2. As an arrow: scaling stretches it

  2 x arrow: twice as long, same direction.
  0.5 x arrow: half as long.
  -1 x arrow: the same length, pointing the other way (every slot flips sign).

# 3. Scale, then add: a combination

  2 x [1, 0] + 3 x [0, 1] = [2, 0] + [0, 3] = [2, 3]

  Any point you can reach by scaling and adding a set of vectors is a combination of them.
