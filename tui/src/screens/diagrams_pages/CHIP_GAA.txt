# 1. What happens: stack the sheets, carve them, release them, wrap the gate

 ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
 │ SUPERLATTICE │   │ FIN PATTERN  │   │ DUMMY GATE   │   │ INNER SPACER │   │ S/D EPI      │   │ RELEASE      │
 │ epi Si/SiGe  │─▶ │ etch stack   │─▶ │ poly + wall  │─▶ │ recess SiGe  │─▶ │ grow source  │─▶ │ etch SiGe    │
 │ alternating  │   │ into fins    │   │ placeholder  │   │ fill SiN     │   │ and drain    │   │ free sheets  │
 └──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘

  (then HK/METAL GATE: ALD high-k + work-function metal wraps every sheet; dummy gate replaced last)

# 2. Cross-section along the channel (current flows left to right through each sheet)

┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│   SOURCE epi (SiP n / SiGeB p)                                              DRAIN epi                  │
│   ░░░░░░░░░░░░ ▓ ═══════════ sheet 3 (Si) ═══════════ ▓ ░░░░░░░░░░░░                                   │
│   ░░░░░░░░░░░░ ▓ ▒▒▒▒▒▒▒▒▒ HK + work-function metal ▒▒▒▒▒▒▒▒▒ ▓ ░░░░░░░░░░░░                           │
│   ░░░░░░░░░░░░ ▓ ═══════════ sheet 2 (Si) ═══════════ ▓ ░░░░░░░░░░░░                                   │
│   ░░░░░░░░░░░░ ▓ ▒▒▒▒▒▒▒▒▒ HK + work-function metal ▒▒▒▒▒▒▒▒▒ ▓ ░░░░░░░░░░░░                           │
│   ░░░░░░░░░░░░ ▓ ═══════════ sheet 1 (Si) ═══════════ ▓ ░░░░░░░░░░░░                                   │
│   ▓ = inner spacer (SiN or SiOCN): isolates gate from S/D at every level;  ▒ = gate wraps all 4 sides  │
│   ───────── bottom: sub-fin / punch-through stop (parasitic channel if not isolated) ──────            │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  (SiGe layers were sacrificial: they set the gap, are etched away, and the gate metal takes their place)

# 3. Epitaxial stack before and after release

 ┌────────────────────┐      ┌────────────────────┐      ┌────────────────────┐
 │ BEFORE RELEASE     │      │ AFTER INNER SPACER │      │ AFTER RELEASE      │
 │ Si    sheet 3      │      │ Si ═════════       │      │ Si ═════════       │
 │ SiGe  sacrificial  │      │ ▓ SiGe recessed    │      │ ▒ gate metal       │
 │ Si    sheet 2      │      │ Si ═════════       │      │ Si ═════════       │
 │ SiGe  sacrificial  │      │ ▓ SiGe recessed    │      │ ▒ gate metal       │
 │ Si    sheet 1      │      │ Si ═════════       │      │ Si ═════════       │
 │ SiGe  sacrificial  │      │ ▓ SiGe recessed    │      │ ▒ gate metal       │
 └────────────────────┘      └────────────────────┘      └────────────────────┘

  (key step: etch SiGe sideways with high selectivity to Si; any Si loss thins the sheet and shifts Vt)

# 4. Process modules that are new versus FinFET

 ┌─────────────────────────────┐   ┌─────────────────────────────┐   ┌─────────────────────────────┐
 │ SUPERLATTICE                │   │ INNER SPACER                │   │ RELEASE                     │
 │ 3-4 Si/SiGe pairs, epi      │   │ isotropic SiGe recess       │   │ SiGe removed laterally      │
 │ thickness ctrl ~1 nm        │   │ then fill + etch back       │   │ needs Si:SiGe selectivity   │
 └─────────────────────────────┘   └─────────────────────────────┘   └─────────────────────────────┘
 ┌─────────────────────────────┐   ┌─────────────────────────────┐   ┌─────────────────────────────┐
 │ HK/METAL GATE               │   │ S/D EPI                     │   │ SHEET WIDTH                 │
 │ ALD into ~10 nm gaps        │   │ grow from sheet edges       │   │ drawn per device            │
 │ stack must fit in gap       │   │ strain + low contact R      │   │ wide=drive narrow=area      │
 └─────────────────────────────┘   └─────────────────────────────┘   └─────────────────────────────┘

  (each module is a place for variation: gap uniformity, recess depth, spacer thickness, gate fill voids)

# 5. Sheet width: a design knob FinFET did not have

┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│   FinFET: fin width is fixed; drive is set by an integer fin count (1, 2, 3 fins)                      │
│      ▐▌  ▐▌  ▐▌                                   thin fins, discrete steps                            │
│   Nanosheet: width W is drawn per device on the same stack height                                      │
│      ▐█████▌   wide sheet: high drive, high speed (high-performance cells)                             │
│      ▐██▌      narrow sheet: low leakage, small cell (dense or low-power cells)                        │
│   Effective width per stack ~ N sheets x (W + 2T), T = sheet thickness (textbook)                      │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  (TSMC says N2 allows cells built from different nanosheet widths on the same chip [3])

# 6. Backside power: signal wires up front, power wires from behind

┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│   FRONTSIDE POWER (conventional)                BACKSIDE POWER (PowerVia / Super Power Rail)           │
│   M10-M14  signal + power mixed, thick          M10-M14  signal only (less congestion)                 │
│   M1-M4    power rails share tracks             M1-M4    signal only                                   │
│   ─────────────── transistors ───────────       ─────────────── transistors ───────────                │
│   substrate (bulk)                              thinned substrate, nano-TSV to rail                    │
│                                                 ═══ BACKSIDE POWER RAILS ═══  to package               │
│   IR droop from long, thin power paths          short power path; wafer thinned (textbook)             │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  (Intel PowerVia debuts on 18A [2]; TSMC Super Power Rail on A16 contacts the source/drain directly [4])

# 8. Roadmap: FinFET to GAA to forksheet to CFET

 ┌────────────────┐   ┌────────────────┐   ┌────────────────┐   ┌────────────────┐
 │ FINFET         │   │ NANOSHEET      │   │ FORKSHEET      │   │ CFET           │
 │ fin, 3 sides   │─▶ │ GAA stack      │─▶ │ wall between   │─▶ │ n stacked on p │
 │ to ~3nm class  │   │ N2 18A SF2     │   │ n and p        │   │ monolithic     │
 └────────────────┘   └────────────────┘   └────────────────┘   └────────────────┘

┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│   imec: outer-wall forksheet extends nanosheets to A10; monolithic CFET expected at A7, after 2030 [5] │
│   CFET stacks NMOS over PMOS: cell area shrinks, but contacts and gates must be built in 3D (textbook) │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
