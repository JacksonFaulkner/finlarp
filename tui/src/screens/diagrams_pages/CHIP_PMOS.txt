# 1. What happens: build a hole-carrying transistor and pair it with an NMOS

 ┌───────────────┐   ┌────────────┐   ┌───────────┐   ┌───────────────┐   ┌──────────────┐   ┌────────────┐
 │ HOLE MOBILITY │   │ N-WELL     │   │ PMOS GATE │   │ SiGe STRESSOR │   │ BORON DOPING │   │ INVERTER   │
 │ holes slow    │──▶│ n-type tub │──▶│ HKMG      │──▶│ recess + epi  │──▶│ p+ S/D       │──▶│ P + N pair │

  (the hole is the weak carrier; every PMOS trick below exists to close the gap to the electron)

# 3. CMOS pairing and why it saves power

 ┌────────────────────────────────────────────────────────────────────────────────────────────────┐
 │  CMOS inverter: one PMOS on top, one NMOS below, gates tied, drains tied                       │
 │                                                                                                │
 │    ┌──────────────────────┐        ┌────────────────────────┐        ┌──────────────────────┐  │
 │    │ PMOS pull-up         │        │ INVERTER               │        │ NMOS PAIR            │  │
 │    │ Vdd to Out when In=0 │        │ In -> Out = NOT In     │        │ Out to Gnd when In=1 │  │
 │    └──────────────────────┘        └────────────────────────┘        └──────────────────────┘  │
 │                                                                                                │
 │     In=0: PMOS on, NMOS off: Out charged to Vdd, no Vdd-to-Gnd path                            │
 │     In=1: PMOS off, NMOS on: Out discharged to Gnd, no Vdd-to-Gnd path                         │
 │                      ┌──────────────────────────────────────────────────┐                      │
 │                      │ CMOS POWER                                       │                      │
 │                      │ only a flip draws current (C*V^2*f)              │                      │
 │                      └──────────────────────────────────────────────────┘                      │
 └────────────────────────────────────────────────────────────────────────────────────────────────┘

  (the two devices are never both on except briefly mid-transition; that is the short-circuit term)

# 5. NMOS vs PMOS balance

 ┌────────────────────────────────────────────────────────────────────────────────────────────────┐
 │  Drive balancing                                                                               │
 │   ┌──────────────────────────────────────────┐   ┌──────────────────────────────────────────┐  │
 │   │ WIDTH RATIO                              │   │ HOLE MOBILITY                            │  │
 │   │ Wp/Wn about 2-2.5, equal edges [4]       │   │ Si: mu_n 1400, mu_p 450 (textbook)       │  │
 │   └──────────────────────────────────────────┘   └──────────────────────────────────────────┘  │
 │                                                                                                │
 │  Equal drive needs mu_n*Wn = mu_p*Wp; strain narrows the gap, so modern ratios shrink          │
 │  FinFET/GAA: width is quantised in fins or sheets, so PMOS gets more fins or wider sheets      │
 └────────────────────────────────────────────────────────────────────────────────────────────────┘

# 6. Strain and doping

 ┌────────────────────────────────────────────────────────────────────────────────────────────────┐
 │  Strain engineering: how each device is stretched or squeezed                                  │
 │   ┌──────────────────────────────────────────┐   ┌──────────────────────────────────────────┐  │
 │   │ SiGe STRESSOR                            │   │ BORON DOPING                             │  │
 │   │ S/D regrown as SiGe: squeezes channel    │   │ in-situ B in epi; fast diffusion risk    │  │
 │   └──────────────────────────────────────────┘   └──────────────────────────────────────────┘  │
 │                                                                                                │
 │  PMOS: compressive along channel (SiGe S/D). NMOS: tensile (nitride cap, SiC/SiP S/D)          │
 │  Intel 90nm: PMOS +25% drive, NMOS cap +10%, ~2% added process cost [1]                        │
 │  Intel VLSI 2004: PMOS 0.72 mA/um at 1.2 V [2]                                                 │
 │  Applied Centura epi: >65% drive gain at 65nm per IEDM 2004 (vendor claim) [5]                 │
 └────────────────────────────────────────────────────────────────────────────────────────────────┘

 │  Hard parts: Ge oxide quality, junction leakage, boron diffusing into the channel              │

# 8. Who matters

  TSMC (TSM), Intel (INTC) and Samsung   build PMOS stressors in every FinFET and GAA node
  Applied Materials (AMAT)               epi tools; 53% of the epi market in 2004 per Gartner [5]
  ASM International, Kokusai             epi and furnace tools (textbook; no share figure sourced)
  Synopsys (SNPS), Cadence (CDNS)        layout, place-and-route and cell characterisation
  Arm (ARM)                              sells physical-IP cell libraries (textbook)
  NVDA, AMD                              fabless; consume whatever PMOS drive the foundry gives them

  (notes: current revenue and share splits for epi tools are not public in the sources found)
