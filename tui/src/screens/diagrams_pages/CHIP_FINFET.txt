# 1. What happens: stand the channel up as a fin and wrap the gate around it

 ┌──────────┐    ┌──────────┐    ┌────────────┐    ┌──────────────┐    ┌─────────────┐    ┌─────────────┐
 │ SAQP     │    │ FIN FORM │    │ FIN REVEAL │    │ GATE WRAP    │    │ QUANTIZED W │    │ FIN COUNT   │
 │ 4x pitch │ ─▶ │ etch Si  │ ─▶ │ oxide      │ ─▶ │ hi-k + metal │ ─▶ │ width = N   │ ─▶ │ 1 to 3 fins │
 │ split    │    │ fins     │    │ recess     │    │ 3 sides      │    │ fins        │    │ per cell    │
 └──────────┘    └──────────┘    └────────────┘    └──────────────┘    └─────────────┘    └─────────────┘

  (fins are cut from the substrate, oxide fills between and is etched back, the gate drapes over the fin)

# 5. FinFlex: pick fins per cell block on N3

 ┌─────────────────┐  ┌───────────────┐  ┌─────────────┐  ┌──────────────────┐
 │ FINFLEX         │  │ 3-2 FIN       │  │ 2-2 FIN     │  │ 2-1 FIN          │
 │ 3-2 / 2-2 / 2-1 │  │ speed         │  │ balanced    │  │ low power, dense │
 │ per block       │  │ 3-fin + 2-fin │  │ 2-fin cells │  │ 2-fin + 1-fin    │
 └─────────────────┘  └───────────────┘  └─────────────┘  └──────────────────┘

  libraries are 1, 2, 3 fins tall; all three options use 2-fin cells as the base; per block, same die [6]
  density range 0.64x to 0.85x of N5 2-2 cell area depending on option (TSMC claim, via Wikipedia mirror) [5]

# 7. What limits fins below 3nm

 ┌───────────────┐    ┌───────────────┐    ┌─────────────┐
 │ FIN LIMITS    │    │ LEAKAGE       │    │ WAFER COST  │
 │ Wfin too thin │ ─▶ │ sub-fin, GIDL │ ─▶ │ N3 vs N5    │
 │ Hfin too tall │    │ tunneling     │    │ price rises │
 └───────────────┘    └───────────────┘    └─────────────┘

  taller, thinner fins bend and etch with tapered profiles, and thinner fins raise variability (textbook)
  (the response in the industry is nanosheets / GAA at N2, Samsung 3nm already; see GAA)
